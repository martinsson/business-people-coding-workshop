# Wishlist — facilitator tooling & portfolio

Captured 2026-06-18. Backlog of improvements for the "Business People Coding" workshop.

1. **Publish/close script.** A script that does the closing/publishing of a session
   (snapshot each group's app into the portfolio repo, add cards, push).
2. **Beautiful portfolio.** Make the portfolio website (`business-people-coding`) genuinely
   nice to look at, not just a card grid.
3. **App previews.** Add a preview/image of each app to its card — ideally enlarge/zoom on
   hover. May require a layout change to give images more room.
4. **Publish today's session.** A session ran today (2026-06-18); it should be published.
5. **Chain reset after publish.** The publish script should probably call the reset script
   at the end (publish → then reset the group repos to the starting point).
6. **Document the workflow.** Briefly document the publish + reset workflow — the code is the
   documentation, but the entry points and the overall flow should be easy to find.
7. **Easy real-LLM access from apps.** Give participants an easy way to call a real LLM from
   their app — any publicly available LLM would do; if none is suitable, decide a nice way to
   provide a token.
